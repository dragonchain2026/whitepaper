# Dragonchain Whitepaper

Dragonchain 白皮书多语言版本 / Multi-language versions of the Dragonchain Whitepaper.

Dragonchain 是一个基于工作量证明（PoW）的去中心化点对点电子现金系统，融合了 Sugarchain 的极速交易能力与 Tidecoin 的后量子安全特性，采用 Falcon-512 后量子签名、Yespower CPU 友好挖矿，5 秒出块时间。

Dragonchain is a decentralized peer-to-peer electronic cash system based on proof-of-work (PoW), combining Sugarchain's ultra-fast transactions with Tidecoin's post-quantum security, using Falcon-512 post-quantum signatures, Yespower CPU-friendly mining, and 5-second block times.
